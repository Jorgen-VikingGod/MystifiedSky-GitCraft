# Commit-message dictionaries

The bundled Hunspell files come from LibreOffice Dictionaries at commit
[`79195b0`](https://github.com/LibreOffice/dictionaries/tree/79195b017e6d70151337856c59e7d13d311d6630).

- `en_US.aff` and `en_US.dic` use the SCOWL-derived English dictionary. See `LICENSE-en_US.txt`.
- `es_ES.aff` and `es_ES.dic` use the RLA-ES Spanish dictionary under MPL 1.1. See `LICENSE-es_ES.md` and `MPL-1.1-es_ES.txt`.
